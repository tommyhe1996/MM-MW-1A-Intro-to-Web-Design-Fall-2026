and learning progress for MM/MW 1A – Intro to Web Design.

- HTML

- Content Management Systems

## Course Goals

Through this course I will develop foundational web-design skills,
construct web projects, participate in collaborative and peer-feedback
activities, and develop a final Content Management System project.
